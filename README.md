# WorldSkills: учебный анализ данных пекарни

В репозитории лежат три исходные CSV-таблицы, учебные скрипты анализа и сохранённые результаты. `worldskill.py` в корне — раннее сквозное решение; `roadmap2/analysis_task.py` — более подробная работа по [плану обучения](roadmap2/ROADMAP.md). Это учебные данные и упражнения, не промышленная аналитическая система.

## Запуск подробного анализа

Проверено с Python 3.13. Установите зависимости из `roadmap2/requirements.txt` в отдельное окружение, затем запускайте из папки `roadmap2`: скрипт читает её CSV и записывает туда же отчёты. Для безопасного пробного запуска скопируйте `roadmap2` во временную папку, чтобы не перезаписать сохранённые результаты.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r roadmap2\requirements.txt
cd roadmap2
..\.venv\Scripts\python analysis_task.py
```

На Linux/macOS используйте `.venv/bin/python`. Графики сохраняются как PDF, сводка — как XLSX, очищенные таблицы — как CSV. Скрипт использует случайные подстановки для некорректных дат с фиксированным зерном; такие даты являются учебной имитацией и не подходят для реальных выводов. Анализ и прогноз следует интерпретировать только в контексте этих данных.
